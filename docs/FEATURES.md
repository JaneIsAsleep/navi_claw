# Navi 功能对照表

核对日期为 2026 年 11 月 28 日，以仓库当前源码和已有验收记录为准。CLI 指 `./navi` 的命令行子命令，TUI 指 `./navi tui` 全屏终端界面，Web 指本机浏览器界面。三个入口共用同一个 Gateway 和持久状态。

表中列出各通道可实际使用的入口。**对话**表示通过当前通道向助理提出请求，执行取决于模型和 Gateway 的权限。**后台**表示由 Gateway 统一执行。**暂无**表示该通道没有对应操作入口。仅能查看时会单独注明。

## 对话与搜索

| 功能 | CLI | TUI | Web |
|---|---|---|---|
| 主对话、新建与继续副对话 | `chat`、`chat --new-session`、`chat --session ID` | 侧栏选会话，`Ctrl+N` 新建 | 对话页与历史侧栏 |
| 历史消息、会话列表和自动标题 | `sessions`、`session`、`messages`。标题由后台生成 | 侧栏与消息区 | 历史侧栏与对话页 |
| 搜索标题、正文与封存话题 | `search-sessions` 默认查标题，`--all` 查正文，支持分页与最近对话 | 侧栏搜索标题和正文，最多 50 条 | 搜索面板支持分页、命中片段及原消息定位 |
| 重命名、封存、解封副对话 | `rename-session`、`archive-session`、`unarchive-session` | 可解封，暂无重命名与封存入口 | 副对话菜单与解封按钮 |
| 查看删除影响、永久删除副对话 | `deletion-impact`、`delete-session` | 暂无 | 删除确认框列出关联提醒 |
| 重置主对话 | `reset-main --yes` | 暂无 | 主对话菜单确认重置 |
| 标记会话已读 | `read-session` | 打开活跃会话时标记 | 浏览当前对话时标记 |
| 流式回复、等待与停止 | `chat --stream`、`chat --wait`、`job`、`cancel-job` | 流式预览、停止当前聊天作业 | 对话流式回复与停止 |
| 引用记录讨论 | `chat --reference ID`，最多五条 | 动态页「带引用讨论」，一次携带一条动态 | 引用条目讨论，最多五条，支持边看动态边聊 |
| 长会话摘要与手动压缩 | 后台自动压缩，`compact` 手动发起 | 后台自动压缩，暂无手动入口 | 后台自动压缩，设置页可准备手动压缩 |
| 排版、草稿和阅读位置 | JSON 回执与文本增量，无输入草稿管理 | 纯文本消息，运行期间按会话保存输入草稿 | Markdown 排版，本机浏览器保存草稿、会话与阅读位置 |
| 对话级公开网页搜索 | `web-search`、`chat --web-search`、`chat --no-web-search` | 对话下方的联网开关 | 输入框上方的联网开关 |
| 原生搜索能力检查及第三方回退 | `check-native-search --wait`、`search-settings` | 设置中的原生搜索测试与第三方配置 | 设置中的原生搜索测试与第三方配置 |

## 提醒、审批和运行记录

| 功能 | CLI | TUI | Web |
|---|---|---|---|
| 创建单次、周期及 Heartbeat 提醒 | `schedule` 支持相对和当地时间、间隔、会话及关联目标 | 可在对话中安排提醒，提醒页暂无创建表单 | 提醒事项表单支持三种类型及关联目标，也可用对话 |
| 查看提醒、下次触发和执行历史 | `schedules`、`schedule-history` | 提醒页显示归属、类型、时间和状态，暂无执行历史入口 | 提醒事项及「历史与失败」 |
| 编辑、暂停、恢复、取消或完成提醒 | `edit-schedule`、`pause`、`resume`、`cancel-schedule`、`complete-schedule` | 可在对话提出提醒修改，提醒页暂无管理按钮 | 提醒事项，目标页也可结束追踪 |
| 从列表移除已结束提醒 | `remove-schedule` | 暂无 | 提醒事项「从列表移除」 |
| 查看、添加、编辑、完成和删除关注事项 | `check-items list/add/edit/delete`，`replace` 支持 JSON 批量替换 | 暂无 | 提醒事项中的关注事项，支持逐条操作 |
| 到期作业、Heartbeat 静默及提醒归属 | 后台执行。用 `jobs`、`schedule-history` 查询 | 后台执行。提醒与活动页可查看状态，聊天显示已投递提醒 | 后台执行。提醒事项、活动与聊天显示相应记录 |
| 日常自动投递与严格逐条审批策略 | `settings set --notification-policy` | 设置中的提醒审批策略 | 设置中的提醒与授权 |
| 查提案、批准与拒绝 | `actions`、`approve`、`reject`，提交所见版本的 `--hash` | 审批页查看并二次确认 | 审核请求与关联对话的审批卡 |
| 修改待审批提案并重新审批 | `edit-action`。可编辑通知或文档提案，修改后使用新哈希 | 暂无 | 审批卡「编辑后重新审批」 |
| 目标或提醒的对话修改提案 | 对话发起，`actions` 后按哈希决策 | 对话发起，审批页决策 | 对话发起，在审批卡或审核请求决策 |
| 版本、Outbox、投递与失败记录 | `action-history`、`evidence`、`audit` | 审批页可看当前版本与状态，暂无历史明细入口 | 审批卡「版本与执行记录」与活动详情 |
| 核准后写出文件、拒绝后保持未执行 | 后台执行，可用审批与成果命令核查 | 后台执行，可用审批与成果页核查 | 后台执行，可用审核请求与成果库核查 |
| 查看通知、标记已读及确认收到 | `notifications`、`read-notifications`、`acknowledge`、`dismiss-reminder` | 对话显示投递的提醒，审批页可点「收到」 | 对话提醒卡与审核请求可点「收到」 |
| 近期作业、取消、超时和恢复 | `jobs`、`job`、`cancel-job`、`evidence` | 活动页看状态及错误，聊天可停止当前作业 | 跟进记录、对话停止与详细记录 |
| 按作业或全局查看审计 | `audit --job ID`、`audit` | 暂无专用审计入口 | 设置的完整运行记录、活动页的作业详情 |

目标或提醒的待审批修改提案若需调整，先拒绝旧提案，再在对话中发起新修改。审批后的写入范围是 Navi 的成果目录。通过成果库主动下载可选择浏览器或 CLI 保存路径。提醒通常投递到创建话题。话题封存期间转发主对话，解封后新提醒回归原话题。

## 动态、订阅与设置

| 功能 | CLI | TUI | Web |
|---|---|---|---|
| 浏览动态、翻页和核对来源 | `feed list --before`、`feed show` | 动态列表、加载更多与来源文本 | 动态消息页、分页、来源链接与失败重试 |
| 动态配图预览 | 暂无独立图片命令 | 暂无 | 预览原始来源配图 |
| 编辑关注说明 | `feed brief`、`settings set --feed-brief` | 暂无 | 动态选项中的关注说明 |
| 预览并添加公开 RSS/Atom、关注预设来源、暂停和恢复 | `feed sources/follow/preview/add-source/toggle-source` | 暂无 | 动态选项中的来源管理 |
| 定时生成动态与构想、故障后的有限恢复 | 后台执行，`status` 可查看日更状态 | 后台执行，动态、构想和活动页查看结果 | 后台执行，动态与构想页显示最近更新和失败状态 |
| 手动拉取订阅或生成动态简报 | `feed refresh`、`feed generate --wait` | 暂无 | 暂无直接入口 |
| 模型密钥及真实连接测试 | `settings set --set-key`、`settings check --wait` | 可为当前连接保存密钥，暂无通用连接测试。另有原生搜索测试 | DeepSeek 连接设置及真实连接检查 |
| 模型名、协议及自定义 Endpoint 新增、选择和删除 | `settings set`、`settings delete-endpoint` | 可查看当前模型和协议，暂无修改入口 | DeepSeek 连接设置和高级设置 |
| 第三方搜索服务及其密钥 | `search-settings` 或 `settings set`，隐藏输入密钥 | 设置中的服务选择和密码输入 | 第三方搜索设置 |
| 时区、简报工作流、调用期限和预算 | `settings set` | 暂无修改入口 | 设置中的时区、高级设置与预算 |
| 当日请求、Token 及费用估算 | `settings usage`、`status` | 暂无 | 设置中的今日使用 |
| TUI 命令面板、侧栏与键盘导航 | `./navi tui` 打开 | `F1` 命令面板、`F2` 侧栏，窄终端自动收起侧栏 | 浏览器导航、响应式布局与双栏界面 |

网页搜索按对话授权。对已验证的模型连接优先使用 DeepSeek 原生搜索，未验证或请求实际失败时可使用已配置的第三方搜索。公开订阅读取和聊天搜索各自独立。简报工作流可选重要事项或临近截止事项。每日动态与构想按配置时区计划在 06:00 运行，恢复后最多补最近的批次。

## 运行与验证边界

| 功能 | CLI | TUI | Web |
|---|---|---|---|
| 启动、停止、查看服务状态 | 项目根目录 `start.command`、`stop.command`、`status.command`，亦可用 `./run` 前台运行。`./navi status` 查询运行中 Gateway | 顶栏显示连接状态。退出 TUI 后已启动的 Gateway 继续运行 | 打开本机入口。关闭页面后已启动的 Gateway 继续运行 |
| 状态持久化、重启恢复及防重复执行 | 共用本机 Gateway 和 SQLite 状态 | 共用本机 Gateway 和 SQLite 状态 | 共用本机 Gateway 和 SQLite 状态 |
| 指定本机目录作为工作区、任意文件操作、运行 Shell 命令 | 暂无 | 暂无 | 暂无 |
| 完全离线的模型推理 | 当前生成依赖配置的模型服务 | 当前生成依赖配置的模型服务 | 当前生成依赖配置的模型服务 |
| 云端虚拟机、复杂影音制作、跨网站交易与外部消息投递 | 未实现 | 未实现 | 未实现 |

日常启动时服务仅绑定本机，凭据保存在本机。生成任务会把相关会话、摘要、有效记忆和引用资料发往配置的模型服务。停用的记忆不参与后续调用。电脑休眠、关机或 Gateway 停止期间不会实时处理任务。
