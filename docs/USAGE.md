# Navi 使用说明

本机入口为 [Navi](http://127.0.0.1:8766)。DeepSeek 密钥留在本机，最近实际验证的模型为 `deepseek-flash`，使用 Messages 协议。检查当前服务使用 `status.command`。

项目根目录为本机克隆的 `navi_claw` 文件夹。Windows/WSL2 的首次安装见 [README](../README.md)。

macOS 双击项目根目录的 `start.command` 启动，Windows/WSL2 在 Ubuntu 终端执行 `./start.command`。看到“已就绪”后可以关闭启动终端，WSL 环境仍须保持运行。关闭浏览器也不会停止后台。普通提醒实际投递到创建对话，封存期间转主对话并标明来源。真正关闭使用同目录的 `stop.command`；`status.command` 可查看状态、入口和日志位置。不要直接打开 `frontend/index.html`。

如果使用 `./run` 前台启动，需要保留该终端，按 `Ctrl+C` 停止。请先停止后台，再使用这个入口。电脑休眠、关机或后台停止期间不执行任务；恢复后，每个调度最多补做一次最近错过的检查。

首次进入唯一主对话，以后恢复最近有效话题、输入草稿和阅读位置。主对话不能重命名、封存或删除。新副对话在发送首条消息后进入历史，更多菜单支持重命名、封存和永久删除。搜索覆盖当前页面，默认显示最近二十条主题及展示摘要，可继续加载。Web 匹配标题和已保存消息正文，正文命中显示片段并定位原消息；CLI 默认按标题检索。包含封存话题，搜索及查看不调用模型，关闭后保留草稿、详情和阅读位置；打开匹配只查看历史，点击明确解封或直接请 Navi 解封后才恢复。永久删除前列出关联提醒，取消不会修改数据；确认后删除消息与摘要，取消相关未完成提醒及未决动作。独立保存的目标、记忆、成果和必要执行记录仍保留。

可以说“记住：请用简洁中文回答我”，或从头像 → 身份信息 → 记忆逐条添加、编辑、启停。记忆回执可直接定位对应条目。目标分类先显示说明，点击“现在就开始”才开启副对话并自动提问；关闭说明不保存。选项嵌在聊天气泡内，选中状态和当前草案会持久保存。最多两次答复后确认目标，保存后再补细节。桌面可打开、收起并排聊天或展开完整聊天，窄屏切换保持同一草稿和卡片。明确“确认目标：具体内容”也可保存；缺少草案时单独确认不会保存。勾选完成立即结束关联工作及未投递动作，完成行约三秒后移走；请求失败会恢复勾选。已完成列表提供恢复及删除确认，删除将目标移出列表，保留相关对话、文件与审计。恢复目标不会复活旧提醒。

头像 → 提醒事项添加单次、周期或 Heartbeat 提醒，并可关联目标；这里新建的提醒归属主对话，保存前明确显示归属。调度支持暂停、恢复、修改时间、取消与查看完整历史，同时仅允许一个 active/paused Heartbeat，已结束的历史任务不占名额。无关提醒不会仅凭旧聊天中的目标自动关联。关注事项单独管理，其截止日期不会自动变成提醒。

“动态消息”右上“动态选项”提供关注说明和来源管理，说明只影响以后生成的内容。保留 [OpenAI 官方动态](https://openai.com/news/rss.xml)、[Python 官方博客](https://blog.python.org/feeds/posts/default?alt=rss) 和 [NASA 官方新闻](https://www.nasa.gov/news-release/feed/)。可以输入公开 HTTPS RSS/Atom 地址，预览标题和最新三条后确认添加；改变地址须重新预览，确认时再次读取，重复地址沿用原来源。可关注、暂停或恢复，普通网页和失败原因明确显示。每个启用来源读取最新三条资料，实际失败原因和最近成功时间保留。

每日当地 06:00 自动整理零至五条独立内容，通常每条两段、140 至 300 字，资料不足时可以更短。先读订阅正文，必要时最多补读五篇订阅提供的公开文章，保存实际读取范围。正文完整显示，来源和发布时间可以核对。真实来源配图可点击查看大图，图片失败保留彩色图标与正文。列表每次加载二十条，继续向下阅读或点击“加载更多”；失败可以重试，已有条目保留。未填写关注说明时当日不生成文章，来源和生成故障均如实显示。

点击动态的“讨论”后，桌面保留右侧动态，在左侧聊天显示“正在回复 Navi”和可移除引用；当前普通活动话题优先，归档或目标引导话题回到已有主对话。原草稿和其他引用保留，再点击另一条只替换本次动态引用，最多五条引用。不会自动发送或预填指令，写好问题后由你发送。可以收起聊天、展开完整聊天再返回，窄屏通过动态/聊天切换保留阅读位置。若引用在发送前失效，页面提示并保留草稿。

构想每日当地 06:00 自动生成。完整五条校验通过后原子替换上一批，失败保留旧批，首次失败保持真实空态。详情弹窗说明我帮你做什么、包含的项目和运作方式，点击“现在就开始”立即建副对话并发送，无需再次发送。已经变为历史的卡片不能启动。成果库只提供查看和下载，聊天中的文档导出仍需要审批。电脑休眠或 Gateway 停止时无法定点执行；启动或检测到运行间断后等待连续清醒六十秒，只补最近一个已到批次。网络或休眠中断最多延迟恢复两次，分别等待十、三十分钟，成功作业不重跑。

Heartbeat 在“优先事项”工作流中检查本机重要事项与已关注订阅。有变化时产生提醒，无事或未变化时保持安静。“临近截止”工作流只选有截止时间的事项，因此不包含没有截止日期的 RSS。订阅材料和补读文章按实际读取范围记录，重要事实应打开原始来源核对。

普通站内提醒默认按已有授权发送，投递时读取创建话题的封存状态，切换当前页面不会改变目的地。解封后的未来提醒回原副对话，已投递历史不搬动。严格策略先显示待审提案，获准后才形成实际提醒消息。

文档导出会展示完整内容、文件名和版本，等待你批准；拒绝后不会投递，编辑提案后需要重新审批。原回复与头像 → 审核请求共用同一个动作；无来源后台提案只出现在审核请求。版本与执行记录可核对旧版本、批准内容和实际结果。课程演示原始逐条通知审批要求时，请在设置中切换为“严格”策略。成果库区分草稿与已导出文件，两者均可下载当前真实内容，并回原话题或带引用讨论。

对话和后台生成会把当前会话、摘要、有效记忆、进行中的目标、待办上下文及本次来源资料发送给配置的 DeepSeek。停用的记忆不参与后续回答。密钥保存在本机，不需要发送到聊天中。

本机每日请求与 token 限制现为 0，表示不按日总量拦截，用量仍逐次记录，服务商额度仍有效。单作业最多 5 次模型请求、10 次工具调用、180 秒执行窗口；自动内容跨延迟恢复累计不超过 60000 tokens。重试、压缩和开发验收均记账，设置页可以查看实际用量。费用未配置费率时不会显示为免费，实际收费以服务商账单为准。

本轮细化开发的界面测试使用独立 `engineering/verification/.cache/refinement-preview` 数据，不写入日常个人条目。首次模式迁移前自动保存原数据库 `data/navi.before-refinement.sqlite3`。旧会话成为副对话，原消息、摘要和标题保留；可验证关系继续使用，缺失来源明确显示暂无关联对话，旧通知仅在提醒历史追溯。

源码、锁定依赖、原始要求、批准计划、架构说明和验收证据均在项目目录。当前实现包含聊天、记忆、目标跟进、任务、动态、建议、轻量成果及审批。云端虚拟机、完整影音工作流和跨网站交易保持此前约定的范围边界。外部读取支持预设及用户确认的公开 RSS/Atom、其中已提供的公开文章和来源配图。

复现离线检查执行 `./test`；真实 API 验收执行 `./test --live`，会消耗模型额度并使用隔离固定数据。新机器首次运行先执行 `./setup`，需要 Python 3.12、uv 和 Node.js 22.12 或更高版本。完整操作与 CLI 示例见项目 README。
