## 实际验证

2026-10-04 的 `./test`：53 passed，1 个既有 Starlette/httpx 弃用警告，4.59 秒。涵盖原测试与 23 项细化测试，包括删除和不可取消导出的并发边界，以及明确工具委托缺少实际回传时的纠正和失败处理。新增回归场景在修正前实测 3 项失败，修正后全部通过。此前前端 `npm run build` 已完成 TypeScript 检查和生产构建；本次没有前端改动。新增验收脚本已做语法编译，`git diff --check` 通过。

原有 `./test --live` 在本轮通过，证据时间为 2026-10-03 05:31 UTC，使用真实 DeepSeek。检查真实工具回传、Heartbeat 静默、严格拒绝及批准、日常提醒、真实 RSS、压缩继续、文档导出和恢复，见 [真实接口报告](../04-muse-revision-v1/implementation/live-evidence.json)。最后的只读工具守卫与旧数据兼容修正发生在该次调用之后，后续以离线测试验证。

新增 `./test --live --refinement` 于 2026-10-04 01:50:29 至 01:50:46 UTC 通过。使用真实 `deepseek-flash`、Messages 协议和隔离数据，七项检查包含：保存目标和记忆且不自动提醒、修改下一步、单次提醒严格审批后按封存状态转主对话、通过真实工具解封、解封后周期提醒回原话题、编辑提案后重新批准并实际导出、删除取消关联工作并重建验证。共 13 次模型请求，回执记录输入 27117 tokens、输出 1506 tokens，已计入日常预算；三个动作各投递一次，另一个待审导出被删除操作作废。详见 [新增闭环证据](../04-muse-revision-v1/implementation/refinement-live-evidence.json)。

首次真实运行在创建单次提醒处失败，模型回复已设置提醒，但本作业没有工具或调度记录，见 [首次失败证据](live-initial-failure.json)。原因是 `Agent.execute` 接受纯文字作为成功结果。本次对用户明确指定调用的可用工具核对当前作业的成功回传，发现遗漏时纠正一次，仍未完成则返回失败；拒绝或无效参数的工具回传不算成功。纠正指令只要求补齐遗漏操作，回归测试确认该流程中的已保存记忆没有重复创建。解释工具或明确禁止调用不会被要求执行。统一执行入口的检查涵盖聊天和草稿；会话压缩仅生成摘要，沿用其摘要检查。

此次闭环脚本为多数委托明确给出工具名和参数，解封通过自然语言请求完成。它验证真实工具、持久状态与投递结果，日常表达和持续帮助的实际体验继续由一周试用记录检验。2026-10-03 的 [界面记录](ui.json) 保留当时未执行新增模型闭环的历史状态，不作为本次模型证据。

[界面记录](ui.json)与启动检查使用 `engineering/verification/.cache/refinement-preview` 独立固定数据，没有模型调用。固定回复和中断状态只用于界面验收，未作为真实模型能力证明。UI 操作后实际投递一次文件、拒绝动作无 Outbox，文件下载 SHA-256 为 `9d3e9c475253d44e45d836c24e2a24d6cc85b3faaf5a43e14975dacae0d81ac8`，下载文件与隔离导出文件字节相同。

启动器、停止器和状态入口的实际检查见 [本机运行报告](runtime.json)。报告确认启动器退出后进程由 PID 1 托管且无终端、重复启动复用进程、正常停止入口断开、重启保留数据及 CLI 生命周期与 Web 一致。原生终端窗口关闭未再次单独演练，脱离终端进程已实测。实际关闭验收浏览器后，空事项后台检查完成且静默，零模型调用及投递。随后已恢复原 data 目录的日常服务，重新打开网页并确认主对话可用。
